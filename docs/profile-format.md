# Контракт профиля

Текущая версия 0.3, JSON без NaN/Infinity. Профиль описывает одну позицию. `source` — `synthetic`, `real` или `unknown`; эта отметка отражает происхождение, а не подтверждение точности.

Единицы `response.unit` — только `dB`; явно указанные другие значения отклоняются. Отсутствующее поле допускается для совместимости со старыми файлами. Веб-экспорт сохраняет описанные ниже поля, а не все произвольные поля исходного JSON; исходные файлы сеанса храните отдельно.

```json
{
  "roomscope_version": "0.3",
  "label": "Позиция A",
  "source": "synthetic",
  "microphone": "unverified",
  "peq_status": "suggestions-only",
  "peq_filters": [],
  "response": {
    "reference": "sweep-relative",
    "unit": "dB",
    "centers_hz": [100, 125, 160],
    "smoothed_db": [1.2, 0.5, -2.1]
  }
}
```

Частоты конечные, положительные, строго возрастают. Число значений совпадает с числом частот. Веб-импорт ограничен 1 МБ, 2–256 полосами, диапазоном частот 1–100000 Гц, уровнями ±300 дБ и названием до 120 символов. Текущий pipeline сохраняет только полосы, полностью лежащие внутри частот sweep (29 полос при 20–20000 Гц). При загрузке неизвестная версия отклоняется; ошибочный файл не заменяет текущий профиль.

Для сравнения необходимы одинаковые частоты и `reference`. Версия 0.2 без `reference` распознаётся как `legacy-peak-normalized` и не смешивается с 0.3. Старые профили без АЧХ не могут быть восстановлены из одних PEQ-фильтров — нужен повторный расчёт из записи/IR. Старые нормализованные WAV тоже не восстанавливают потерянный абсолютный уровень.

`sweep-relative` сохраняет уровень после нормализации inverse filter к пику его самосвёртки со sweep. Это сравнительный уровень тракта; это не калиброванный SPL и не универсальная абсолютная шкала. Сравнивайте измерения с тем же sweep, конфигурацией входа/выхода и усилением. На краях sweep возможен спад из-за окон. RMS — корень среднего квадрата B−A по полосам, без знака и без оценки «лучше». Средняя дельта имеет знак.

PEQ-предложение: `{ "type": "peak", "freq_hz": 63, "gain_db": -4, "q_factor": 2 }`. Новое ядро предлагает только срезы, но импорт сохраняет старые положительные gains для совместимости. Фильтры нигде не применяются автоматически.

Данные localStorage привязаны к origin браузера. Смена порта, браузера, очистка данных или приватный режим могут убрать их. JSON-экспорт — переносимая копия. Файлы остаются на устройстве и не отправляются на сервер.
