# Технический аудит RoomScope — 2026-10-05

Повторная проверка и актуальные требования к очкам: [отчёт от 5 октября](requirements-and-xreal-review.md). В нём учтены две дополнительные регрессии импорта; текущие результаты — 5 тестов модели, 29 DSP, 12 браузерных на dev и 12 на production. Ниже сохранены результаты первого этапа восстановления.

## Исходное состояние и задумка

Проверены обе ревизии истории: `2d357e9` (выгрузка сайта 2026-07-28) и `df547db` (фактически добавлен только `.gitignore`). В корне были три HTML и ZIP; README, сборки, управляемых зависимостей и CI не было. `index.html` и `roadmap.html` совпадали побайтово.

В `downloads/roomscope-core.zip` найдены README, Python DSP, конфигурация, восемь тестов, пример неполного профиля, графики и пустая папка Unity. Это подтверждает фазовый замысел: сначала акустическое ядро на компьютере, затем spatial-рендер на XREAL/Android, мобильный RTA/A/B, потом модель мод и подсказки расстановки. Работающего native AR в репозитории нет. Исходный ZIP оставлен неизменным для истории; его исходники вынесены в `roomscope-core/` для обычного review и тестирования.

Исходный UI осмотрен в браузере из локальных HTML. На мобильном экране шапка обрезалась, элементы AR теснились. Случайные значения выдавались за LIVE RTA / dB SPL, microphone connected и tracking locked, хотя доступа к устройствам не было. Веб-лаборатории для реального JSON из Python не было.

## Оставшиеся риски

- **Аппаратная часть не проверена.** Нет подключённых XREAL, UMIK-1 или подтверждённого Android USB-аудиотракта. Тест записи использует mock, реального проигрывания sweep в этой работе не было.
- **Точность ограничена прототипом.** Нет microphone calibration, clock drift compensation, noise-floor correction, сертифицированной RT60/PEQ методики, абсолютного SPL. Нужен эталонный измерительный тест. Не сравнивать разные sweep/уровни/устройства как одну шкалу.
- **Native AR отсутствует.** Трекинг, mesh/anchors, live RTA, моды и стрелки остаются следующими фазами. Статический сайт этого не заменяет.
- **Совместимость оборудования требует проверки.** [Документация XREAL](https://docs.xreal.com/XREALDevices/XREAL%20Glasses) проверена 2026-10-05: SDK docs 3.1.0, 6DoF у Ultra подтверждён; сайт также предупреждает о совместимости Android 16. Факт второго USB-C на хосте не доказывает возможность одновременного подключения USB-микрофона.
- **Хранение локальное.** A/B сохраняется только в текущем browser origin; экспорт JSON нужен для переноса/резервной копии. Новая библиотека многих сеансов, синхронизация и undo ещё не реализованы.
- **Платформы.** Выполнены Windows/Chromium desktop+mobile-emulation. Safari, Firefox и физические мобильные устройства отдельно не проверялись. CI добавлен, его удалённый результат нужно смотреть в GitHub. Публичный сайт не развёртывался.

## Три следующих приоритета

1. Калиброванный эталонный тракт с UMIK-1: повторяемость, loopback/clock drift, сверка АЧХ с независимым ПО.
2. Минимальный Unity/XREAL Android build: стабильная world-locked АЧХ в одной физической точке; подтверждение хоста и USB topology на реальном железе.
3. Сеанс с координатами слушателя/колонок и транспортом Python → Unity; повторное A/B в той же точке. Модель мод и вычисляемые стрелки после этого.
